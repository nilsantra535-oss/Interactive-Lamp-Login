# Interactive Lamp Login 💡

An immersive, interactive web application featuring an animated desk lamp that controls the visibility and theme of a modern glassmorphism login interface. Pull the elastic string to turn on the lamp, choose your favorite lighting color, and experience smooth physics-based interactions!

## ✨ Features

- **Interactive Desk Lamp:** Pull the elastic cord with realistic physics, spring rebound, and a twang effect to turn the lamp on or off.
- **Dynamic Lighting & Themes:** Switch between 5 different lighting themes (Amber, Cyan, Rose, Mint, and Moonlight) which dynamically update the ambient glow, light beam, and particle canvas.
- **Web Audio API Synthesizer:** Real-time generated sound effects for string plucks, switch snaps, and power hums without external audio files.
- **Glassmorphism Login Card:** Modern sign-in and sign-up form with interactive 3D mouse tilt effects, smooth tab transitions, and a success feedback state.
- **Ambient Dust Particles:** Custom HTML5 canvas particle system reacting to the lamp's power and color state.
- **Fully Responsive:** Optimized layout for desktops, tablets, and mobile devices.

## 🛠️ Built With

- **HTML5 & CSS3** (Custom Properties, Flexbox, Glassmorphism UI)
- **JavaScript (ES6+)** (DOM Manipulation, Web Audio API, HTML5 Canvas)
- **GSAP (GreenSock)** & **Draggable Plugin** (For fluid animations and physics)
